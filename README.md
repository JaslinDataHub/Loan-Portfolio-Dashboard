# 📊 Loan Portfolio Dashboard

## Project Overview

This Power BI dashboard provides a complete analysis of a loan portfolio, helping financial institutions monitor loan performance, repayments, overdue loans, penalties, and outstanding balances.

---

## Dashboard Pages

### Page 1 – Portfolio Overview

- Total Loans
- Total Principal
- Outstanding Principal
- Principal Paid
- Interest Paid
- Recovery Rate
- Loan Trend
- Loan Status Distribution

---

### Page 2 – Charges & Penalty Analysis

- Total Charges
- Charges Paid
- Penalty Paid
- Penalty Waived
- Loan Details
- Outstanding Principal Analysis

---

### Page 3 – Overdue Analysis

- Average Overdue Days
- Maximum Overdue Days
- Write-Off Loans
- Outstanding Principal by Substatus
- Average Overdue Trend

---

### Page 4 – Performance Analysis

- Average Principal
- Average Charges Paid
- Average Penalty Paid
- Loan Status Performance
- Penalty Flow
- Loan Substatus Distribution

---
